# Northview Production website

Design system for the Northview Church production department site. Dark by default, built on the Northview Church web brand.

- `design-system/DESIGN-SYSTEM.md` — the spec
- `design-system/tokens.css` — custom properties and base styles
- `design-system/components.css` — component classes
- `design-system/index.html` — living reference page (`reference.png` is a capture of it)
- `design-system/assets/` — logos, topo pattern, photography

View the reference page:

```
cd design-system && python3 -m http.server 8766
open http://127.0.0.1:8766/index.html
```
